# ShopEase – Selenium Automation Testing

## Project Overview
ShopEase is an e-commerce web application. This project focuses on automating browser-based testing of the ShopEase platform using Selenium WebDriver and Java.

The purpose of this project is to verify website functionality and understand automated software testing.

## Technologies Used
- Java
- Selenium WebDriver
- Maven
- JUnit/TestNG (depending on the test framework configured in the project)
- Visual Studio Code
- Chrome Browser

## Project Structure

```text
ShopEase-Selenium-Testing/
│
├── src/
│   ├── main/
│   └── test/
│
├── test-screenshots/
├── pom.xml
└── .gitignore
```

## Features
- Browser automation using Selenium WebDriver
- Automated execution of test cases
- Screenshot capturing during testing
- Maven-based test execution

## Prerequisites
Before running this project, make sure you have:
- Java JDK installed
- Maven installed
- Google Chrome installed
- Selenium dependencies configured in Maven

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/akshatasingh27/ShopEase-Selenium-Testing.git
```

2. Open the project folder:

```bash
cd ShopEase-Selenium-Testing
```

3. Run the test cases:

```bash
mvn test
```
